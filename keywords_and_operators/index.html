    Keywords & Operators Cheat Sheet

    Keywords

    Keyword Description
    let Declare a variable
    if Conditional start
    elif Conditional else-if
    else Conditional fallback
    while While loop
    for For loop
    func Function declaration
    return Return from a function
    true Boolean True
    false Boolean False
    and Logical AND
    or Logical OR
    not Logical NOT
    print (Deprecated internally as keyword, mapped to print function)
    class Class declaration
    extends Class inheritance
    self Current instance reference in methods
    break Break out of a loop
    continue Skip to the next loop iteration
    null Null value
    in For-in loop operator
    try Try block for error handling
    catch Catch block
    finally Finally block (runs after try/catch, or after loops)
    throw Raise an exception
    import Import another module/file

    Operator Description
    + Addition
    - Subtraction
    * Multiplication
    / Division
    // Floor division
    % Modulo
    ** Exponentiation / Power

    Assignment

    Operator Description
    = Assignment
    += Add and assign
    -= Subtract and assign
    *= Multiply and assign
    /= Divide and assign
    //= Floor divide and assign
    %= Modulo and assign

    Comparison

    Operator Description
    == Equal to
    != Not equal to
    < Less than
    > Greater than
    <= Less than or equal to
    >= Greater than or equal to

    Symbol Description

    { } Code blocks, dictionaries
    [ ] Arrays, array indexing, and slicing
    . Attribute access
    : Dict key-value separator, array slicing
    , Item separator
    ; Statement terminator
    ... Spread / Variadic arguments
